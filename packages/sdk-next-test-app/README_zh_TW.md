這是一個使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 引導建立的 [Next.js](https://nextjs.org) 專案。

## 入門指南

首先，啟動開發伺服器：

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
# 或
bun dev
```

使用瀏覽器開啟 [http://localhost:3000](http://localhost:3000) 以查看結果。

您可以透過修改 `app/page.tsx` 開始編輯頁面。當您編輯檔案時，頁面會自動更新。

此專案使用 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) 來自動優化並載入 [Geist](https://vercel.com/font)，這是 Vercel 的一款新字體系列。

部署 Next.js 應用程式最簡單的方法是使用由 Next.js 創作者開發的 [Vercel 平台](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme)。

請參閱我們的 [Next.js 部署文件](https://nextjs.org/docs/app/building-your-application/deploying) 以了解更多詳情。
