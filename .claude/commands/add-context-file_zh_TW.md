在目錄 `$ARGUMENTS` 中新增一個 CLAUDE.md 上下文檔案

<format>
使用 XML 標籤標記章節，而非 Markdown 標題。
允許的標籤：<summary>, <howToUse>, <codeExample>, <links>, <importantToKnow>。
程式碼區塊可使用帶有語言說明的連三個反引號 (backticks)。
繪製圖表請在程式碼區塊中使用 mermaid 語法。
連結檔案時請使用 @/path/to/file.extension。
檔案長度請保持在 50 到 100 行之間。
</format>

<content>
上下文檔案的目的是為了讓開發者能以最快的速度理解如何使用該模組中的檔案。

內容應易於理解且實用，但不需面面俱到。請提供工程師使用該模組內容所需的最簡可行 (minimum viable) 上下文。

簡要總結模組的目的及其價值。
不應涉及技術實作細節。

說明關鍵介面、進入點 (entry points) 和匯出的函式，並提供簡短的使用範例。
程式碼範例不需要涵蓋所有可能的參數或邊緣案例，只需涵蓋最常見的用法。
應具有指引性，而非詳盡無遺。
不要解釋模組的內部實作細節。

您不需要涵蓋所有的業務規則，但應指出任何關鍵的業務邏輯、限制、陷阱，或任何從程式碼本身無法直觀看出的事項。

圖表並非必備，但如果能幫助解釋複雜的流程，請使用 mermaid 語法加入圖表。

連結到外部文件、規格或檔案，而非在此處重複內容。如果涉及複雜的工程概念，請連結至教學課程，以便工程師進一步學習。
</content>

- 在 <codeExample> 標籤和程式碼區塊之間加入換行。
</linting>
