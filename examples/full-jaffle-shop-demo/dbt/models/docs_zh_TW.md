# 訂單狀態

訂單可以具有以下狀態之一：

| 狀態 (status) | 說明 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| placed (已下單) | 訂單已下達，但尚未離開資料倉庫 |
| shipped (已出貨) | 訂單已發送給客戶，目前正在運輸中 |
| completed (已完成) | 客戶已收到訂單 |
| return_pending (退貨待處理) | 客戶已表示希望退回訂單，但倉庫尚未收到退貨 |
| returned (已退貨) | 客戶已退回訂單，倉庫已收到退貨 |
